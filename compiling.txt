Pax Britannica uses git submodules to manage its framework dependencies. If you
downloaded this source copy from git, you need to type
    git submodule update --init
to initialize the framework before compiling.

To compile, use one of the following based on your platform:
Linux:   make linux
OS X:    make macosx
Windows: make mingw

Pax Britannica depends on lua 5.4 and glfw 2.x. The lua flags come from
pkg-config; if your distribution names the .pc file something other than
"lua5.4", pass it in:
    make linux LUA_PKG=lua-5.4
or bypass pkg-config entirely:
    make linux LUA_CFLAGS=-I/usr/local/include LUA_LDFLAGS=-llua

The game logic can also be run without a window, which is handy for checking
that a change didn't break anything:
    lua5.4 test/headless.lua
